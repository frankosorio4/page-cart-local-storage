# Cart-Local storage

Cart-Local Storage is a simple frontend application that simulates how to add and remove items that offer an online store in a cart. This application uses the local store of the browser to perform such tasks. 

## Tecnologies
- Javascript
- CSS
- HTML

## Run

- Clone the repository using **vscode**.

- Once downloaded, you can use the extension **Live server** of **vscode** to see this app locally.
     
## Improvements

Este repositório é de uma App que tem o esquema básico de gestionar Locais para exercitar-se. Por isso tem coisas que podem ser melhoradas.
- Create a frontend project to implement all the features of an online store (Routes, login, register new user, ... etc)
- Create a backend to manage the data safely.
